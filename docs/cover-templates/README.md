# Project cover templates

Each project cover uses a different composition, all on a calm single-color background tinted with the client color:

| File | Composition |
| --- | --- |
| correct.html | standing browser window in slight perspective with a phone in front, soft sage background |
| had.html | iMac with the homepage, two long pages standing beside it |
| mz.html | tilted laptop with two pages floating beside it |
| sc.html | laptop at an angle with a white phone leaning on it and a pencil cup, soft sky-blue and mint background |
| manar.html | two large tilted phones (titanium frame, dynamic island) cropped by the edges, soft lavender background |

Long pages are slices of full-page captures (1440px wide, deviceScaleFactor 1.5), cropped so each slice matches its box ratio.
Render each HTML at 1600×1000 with deviceScaleFactor 1.5 and export WebP quality 90 into `public/projects/<project>/`.
